Cloudflare Worker
1
Go to dash.cloudflare.com/profile/api-tokens → Create Token → use the "Edit Cloudflare Workers" template → copy the token.
2
Find your Account ID: go to dash.cloudflare.com, click any domain (or Workers & Pages) — Account ID is on the right sidebar.
3
Paste both below and click Deploy.
Your worker will be at connect-api-proxy.<subdomain>.workers.dev
This page calls the Cloudflare API directly from your browser. Your credentials are never sent anywhere except Cloudflare's API (api.cloudflare.com).
